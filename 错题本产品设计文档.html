小学错题本（DoOver）产品设计文档

错题本，小题大做 —— V1.0 · 2026 年 11 月 6 日 · 面向三、四年级 · 数学 / 语文 / 英语三科 · 家庭局域网部署

一、产品概述

DoOver 是一个部署在家庭局域网内的错题管理系统，供三、四年级孩子与家长协作使用。核心理念：错题本的价值不在"收集错题"，而在"错过的题不再错"。围绕这一目标，产品解决传统纸质错题本的三大顽疾：

抄题费时间

拍照即录入，错字词走三件套表单，30 秒一道题，家长告别手抄。

复习靠自觉

艾宾浩斯间隔引擎自动排期，每天只推到期题，记完吃灰成为历史。

越积越厚

五档通过即"消灭"，消灭的题进光荣榜，错题本越用越薄。

核心闭环：收集 → 归因 → 间隔重练 → 消灭。每一步都为下一步服务：录入时三秒归因，复习时翻面对照，判定驱动排期，消灭驱动激励。

产品按三、四年级实现：孩子识字量足够，可独立完成复习与自评，家长负责录入与抽查。低年级使用时可降级为"家长代录 + 陪同复习"，高年级可"自录自查"，知识点库支持按年级切换，界面无需改动。

二、用户角色与使用节奏

角色分工
角色职责主要页面
孩子（复习者）独立完成每日复习：看题、纸上演算、翻面对照、三键自评；赚星星、收集勋章今日、我的
家长（教练）拍照录入与归因标注、抽查复核待判定题、查看统计、导出 PDF、管理设置与备份全部页面

一周典型节奏：

  1. 周中 · 每晚作业后

    家长用手机把当天作业、卷子里的错题拍照录入，顺手选好知识点与错因，30 秒一道题。

  2. 周中 · 睡前 10 分钟

    孩子打开「今日」，一题一卡，纸上演算、翻面对照、三键判定，全部通过即收工。

  3. 周五晚

    家长勾选本周错题，导出「重练卷」PDF 打印，周末纸质重练。

  4. 周末

    孩子做重练卷；顽固题由家长坐下来讲透，而不是机械重刷。

  5. 学期末

    导出「收藏本」归档留存；光荣榜保留，新学期错题从零开始。

三、功能设计

3.1 整体结构：五个页面

页面结构
Tab主要使用者核心功能
今日孩子到期复习，一题一卡，三键判定，星星反馈
错题本家长全量列表、筛选、编辑归因、暂停/复活/删除、导出 PDF
加题家长照片题 / 错字词双形态录入

我的共用星星、勋章、光荣榜、奖励规则、设置、备份

「今日」页的复习流程（孩子端核心交互）：

  • 看题 → 纸上演算 → 点「我想好了」→ 翻面对照 → 三键自评 → 自动下一题，底部进度条见底收工。
  • 翻面显示题目照片、正确做法与归因备注；未录答案的题显示「请家长判定」，由家长按键。
  • 错字词翻面为对照视图：孩子错写与正确写法并排，差异字符红色标出。
  • 无到期题时空态文案为「今天没有任务，去玩吧」——不派无谓的活。
  • 界面采用小怪兽卡通风：错题即小怪兽，消灭一题得星星，全程正向反馈。

3.2 录入：双形态，30 秒一道题

形态 A · 照片题

拍照 → 拖框裁剪出这一道题 → 选科目 / 知识点 / 错因，完成。可选补录错误答案（如"写成 47"）与正确做法一句话。适用于数学题、语文阅读题、英语句型题。支持同一张卷子连拍多题批量录入。

形态 B · 错字词

不拍照，表单三件套：提示项（拼音 / 中文）+ 孩子错写 + 正确写法。语文示例：zhì → 写成"志" → 正确"治"；英语示例：中文"星期三" → 写成 Wensday → 正确 Wednesday。复习时自动转为默写重考，一次听写错 10 个字，10 秒录完。

错误原因四分类（录入时三秒选一）
错误原因典型表现干预策略
概念不会知识点没掌握，讲解后能懂回归课本补讲解，重做同类型题
审题马虎看错条件、漏看单位、"比多"看成"比少"抓审题习惯：圈关键词、指读题干
计算失误会做但算错，进位退位出错限时口算训练，养成验算习惯
完全没思路无从下手，翻面也看不懂标记顽固题，家长或老师专题讲解

错因是整个错题本的灵魂。马虎和不会的干预方式完全不同：马虎要抓习惯，不会要补知识。统计页给出占比后，家长立刻知道该补习惯还是补知识。

知识点库：三科预置三、四年级常用知识点——数学：两位数乘除、周长面积、分数初步、应用题；语文：形近字、多音字、近反义词、阅读理解；英语：单词拼写、时态、句型。支持自定义追加，可按年级切换。录入时常用项优先展示。

3.3 复习引擎（核心）

每道错题是一个小状态机，四个状态量：阶段（0~5）、下次到期日、错次、状态（复习中 / 顽固 / 已消灭 / 暂停）。录入次日进入第 1 档，间隔序列 1 → 3 → 7 → 15 → 30 天，通过第 5 档即消灭。节奏与艾宾浩斯遗忘曲线一致。

判定规则与星星
判定状态变化星星
✅ 独立做对阶段 +1，按新档间隔排期+1
⚠️ 提示后才对阶段不变，次日再考0
❌ 又错归零回 1 天档，错次 +10
通过第 5 档（消灭）进光荣榜，不再排期+5
当日清单全部通过—+2
顽固题逆袭消灭错次 ≥3 的题最终消灭+10
  • 每日上限：默认 8 道（可调 3~15），到期超额自动排队到后面几天，不给孩子堆量。
  • 断更不惩罚：几天没打开，到期题堆叠，但依然按上限逐日消化。
  • 顽固题：错次 ≥3 自动标记，清单置顶、统计页高亮，提示家长该停下来讲，而不是机械重刷。
  • 消灭之后：默认不再出现；家长可手动「再考一次」，期末可批量复活抽查。
  • 防放水（默认开）：孩子按的 ✅ 标「待复核」，家长抽查通过才转正；三四年级自评基本可信，但威慑要有，可在设置中关闭。

3.4 PDF 导出：收藏本 + 重练卷双模板

三步向导：① 选范围——按当前筛选（科目 / 知识点 / 状态 / 学期）直接导，或手动勾选，快捷组合含"本学期全部、顽固题专卷、已消灭归档"；② 选模板——收藏本或重练卷；③ 排版选项——按知识点分组（默认）或按时间、顽固题红色高亮置顶、整卷乱序。

双模板对比
维度收藏本模板重练卷模板

  • 题块不跨页（keep-together），顽固题红色边条高亮。
  • 页脚页码；文件名自动生成，如：错题本_数学_三年级上_20261106.pdf。

  • 此功能同时覆盖原定 V2 的"打印组卷"——重练卷模板即打印组卷，同一引擎。

3.6 激励系统：错题即小怪兽

世界观：错题是小怪兽，做对就是消灭它。星星由系统按判定规则自动发放，勋章由复习日志推算，无需手工维护。

  • 勋章墙：初次胜利（消灭第 1 题）、坚持之星（连续复习 7 天）、怪兽猎人（累计消灭 10 题）、怪兽克星（累计消灭 50 题）、翻身仗（顽固题逆袭消灭）、三科通吃（数学 / 语文 / 英语各消灭 10 题）。
  • 光荣榜：被消灭的题按时间陈列为"战利品"，可回看题目与消灭日期。
  • 奖励兑换：规则由家长自定义，如"20 颗星 = 周末选一部电影"，写在「我的」页；孩子可提交兑换申请（内容 + 星数，最多 3 条待审批，可随时撤回），家长批准后从可用余额扣星并留档，驳回不扣；累计赚得只增不减，兑换只影响余额。

4.5 性能设计（防"越用越慢"）

  • 上传前压缩：手机端先压至长边 1200px（约 150KB/张）再上传，局域网传输也快。
  • 缩略图策略：服务端 Pillow 生成缩略图，列表页只加载缩略图，翻面对照才加载原图。
  • 分页与索引：列表接口分页；到期日、科目 + 状态建索引。
  • 小库原则：照片是磁盘文件而非数据库 BLOB，SQLite 只存元数据，常年 <10MB——几年量级下查询不退化。
  • SQLite WAL：读写并发安全；APScheduler 每月自动 VACUUM 保持紧凑。

五、备份与数据安全

  • 每日自动备份：03:30 全量打包 db + photos + manifest（含版本号）为 zip，存 backups/，默认保留最近 30 份，滚动删除。
  • 手动一键备份：「我的」页常驻按钮，录完重要卷子随手按。
  • 备份自检：PRAGMA quick_check 校验库完整性、检查磁盘余量与最近备份年龄；/api/health 暴露给自检脚本，统计页角标超 48 小时变黄提醒。
  • 恢复极简：解压 zip 至 data/ 目录即完整还原；自检脚本带 --verify-backup 校验备份可用性。
  • 第二落盘（可选）：配置额外路径（NAS 其他卷 / 移动硬盘）双保险，配合 fnOS 自身快照兜底。
  • 鉴权与隐私：访问码登录、HttpOnly Cookie；全部数据与备份仅存家庭局域网，零外部上传——孩子的作业、笔迹、姓名不外流。

主要风险提示：纯浏览器方案的风险（清缓存丢数据）已通过服务端架构消除；剩余风险是 NAS 磁盘损坏，靠"每日备份 + 第二落盘 + fnOS 快照"三层兜底。

六、部署与交付

  1. 阶段一 · 开发验收

    Mac 本机 uvicorn 直跑，data/ 在本地；全家设备连同一 Wi-Fi 即可试用，完整走一遍录入 → 复习 → 导出 → 备份流程。

  2. 阶段二 · 生产部署

    从源码全量构建双架构 Docker 镜像（fnOS 用 amd64，arm64 备用）；docker-compose 编排，数据卷映射 NAS 共享目录；容器开机自启，健康检查对接 /api/health。

  3. 交付物清单

    源码、Dockerfile、docker-compose.yml、自检脚本（check.sh：磁盘余量 / 库完整性 / 备份年龄）、README（部署、备份、恢复、回滚、常见问题）。

  4. 回滚策略

    镜像保留历史版本，NAS 上一条命令切回旧版；数据目录与镜像解耦，回滚不动数据。
